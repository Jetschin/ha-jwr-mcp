# JWR Home Assistant Add-ons

Add-on-Repository für Home Assistant OS.

- **JWR Dateien MCP** (`jwr_files_mcp`): MCP-Server, über den Claude Dateien im Ordner `JWR Immobilien GbR` der WD MyCloud lesen, anlegen, verschieben und nach `_erledigt` ablegen kann – ohne Löschen. Details: [jwr_files_mcp/DOCS.md](jwr_files_mcp/DOCS.md).

## Installation

Home Assistant → Einstellungen → Add-ons → Add-on Store → ⋮ → Repositories → URL dieses Repositorys hinzufügen → „JWR Dateien MCP“ installieren.

Alternativ ohne GitHub: Ordner `jwr_files_mcp` über die Samba-Freigabe nach `\\homeassistant\addons\` kopieren, im Add-on Store ⋮ → „Nach Updates suchen“, dann unter „Lokale Add-ons“ installieren.
